# FoodFlow

FoodFlow is a food inventory management application designed to help users keep track of the food they have at home, including their fridge and pantry.

The goal is to make food management easier, reduce waste, and improve grocery shopping through smart features and automation.

## Features

The initial version will include:

- Add and remove food products.
- View available products and quantities.
- Update product quantities.
- Manage food inventory in a simple interface.

Future versions will explore features such as expiration date tracking, shopping lists, consumption predictions, and AI-powered recommendations.

## Tech Stack

- **Frontend:** React, JavaScript
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL

## Status

FoodFlow is currently in the early stages of development. Features and documentation will be updated as the project evolves.
